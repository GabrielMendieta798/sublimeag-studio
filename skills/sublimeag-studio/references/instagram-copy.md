# Copy para Instagram

Escribí en español argentino, cálido y directo. Evitá exageraciones y datos no confirmados.

## Estructura sugerida

1. Una apertura breve centrada en la ocasión o el beneficio emocional.
2. Qué producto es y qué personalización se ve.
3. Datos confirmados: precio, medidas, contenido, plazo o modalidad de pedido.
4. Llamada a la acción realista.
5. Entre 3 y 8 hashtags relevantes; no rellenar con etiquetas genéricas masivas.

Guardá el texto como Markdown en `output/copy/` con el mismo slug de la imagen.

## Límites

- No inventes stock, descuentos, envíos, materiales, tiempos ni componentes.
- No digas "incluye" por objetos que aparecen solamente en la ambientación.
- Para un PRODUCTO GENÉRICO, aclará internamente que es conceptual y evitá publicar especificaciones hasta confirmarlas.
- Si no hay precio, invitá a consultar; no uses un número de ejemplo en la pieza final.

## Plantilla breve

```text
[Apertura]

[Producto y personalización confirmada].
[Precio/datos confirmados, si existen].

Consultanos para personalizar el tuyo.

#SublimeAG #[Producto] #RegalosPersonalizados
```
